# agent-application v0.2.7

**Released 2026-10-27. A patch release**, with lake v0.8.1 ([lake#1260](https://github.com/oramasearch/lake/issues/1260)):
files read exactly; filters applied everywhere. Since [v0.2.6](v0.2.6.md). Private repository and image, `docker.io/oramasearch/agent-application:v0.2.7`.

## What it includes

| PR | Change |
|---|---|
| [#65](https://github.com/oramasearch/agent-application/pull/65) | An App's files are read from their exact bytes (`content_base64`), so Change App and Fix no longer commit `\xNN` escapes into them (#63, lake#1238). |
| [#66](https://github.com/oramasearch/agent-application/pull/66) | Generated Apps apply every filter to every metric, chart and table and keep tables and charts small; a proposal with a widget whose value is never used is refused; a filtered-dashboard eval (#64). |
