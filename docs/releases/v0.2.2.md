# agent-application v0.2.2

**Released 2026-10-26. A patch release.** One change since [v0.2.1](v0.2.1.md): generated Apps call `orama_app`'s
`zetta()` before reading from it, and the agent refuses `zetta.sql(...)` before it commits an App. Image: `docker.io/oramasearch/agent-application:v0.2.2`.

This release is the tree of `dev` at `d0db208` with these notes, the version and the README's release line.

## What it includes

| PR | Change |
|---|---|
| #48 | The prompt shows `zetta()` with an example. `proposal_defects` and repair refuse attribute reads on the bare `zetta`/`service` functions, naming the line and the right form |

Why: an App written by the agent read `zetta.sql(...)`. That compiles, then fails on every page with `AttributeError: 'function' object has no attribute
'sql'`. The prompt's wording ("use its `sql`") invited it, and validation only checked that the code parsed.

## Not included

- Apps already generated are not changed. One that reads `zetta.sql` is fixed by a `repair` turn, or by editing its
  code.

As in [v0.2.1](v0.2.1.md#known-issues).
